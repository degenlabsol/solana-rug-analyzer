## 📱 Quickstart — Android Phone (Termux)

> Tested on Poco X7 and similar mid-range Android devices.

### Step 1 — Install Termux

Download from **F-Droid** (NOT Google Play — the Play version is outdated):  
👉 https://f-droid.org/packages/com.termux/

### Step 2 — Install Node.js & Git

```bash
pkg update && pkg upgrade -y
pkg install nodejs git -y
```

### Step 3 — Clone the repo

```bash
git clone https://github.com/degenlabsol/solana-rug-analyzer.git
cd solana-rug-analyzer/rug-analyzer
```

### Step 4 — Install dependencies

```bash
npm install
```

### Step 5 — Configure

```bash
cp .env.example .env
nano .env
```

Fill in your values (see [Configuration](#️-configuration) below).

### Step 6 — Generate Telegram Session (once only)

```bash
node generate-session.js
```

Follow the prompts → copy the printed string → paste as `TELEGRAM_SESSION` in your `.env`.

### Step 7 — Start the bot

```bash
node index.js
```

### Keep it running after closing Termux

```bash
pkg install tmux -y
tmux new -s rugbot
node index.js
# Detach: press Ctrl+B then D
# Reattach later: tmux attach -t rugbot
```

### Auto-restart on crash (optional)

```bash
# Install pm2 for auto-restart
npm install -g pm2
pm2 start index.js --name rug-analyzer
pm2 save
# View logs:
pm2 logs rug-analyzer
```

## ⚙️ Configuration

Edit `.env` (self-hosted) or Replit Secrets panel.

### Required

| Variable | Example | Description |
|---|---|---|
| `TELEGRAM_API_ID` | `123456` | From [my.telegram.org](https://my.telegram.org/apps) |
| `TELEGRAM_API_HASH` | `abcdef...` | From [my.telegram.org](https://my.telegram.org/apps) |
| `TELEGRAM_SESSION` | `1BQA...` | Generated by `node generate-session.js` |
| `POST_CHAT_ID` | `@mychannel` | Where the bot posts calls |
| `SOURCE_CHAT_IDS` | `chat1,chat2` | Source chats to monitor (comma-separated, no @) |

### Optional API Keys

| Variable | Service | What it adds |
|---|---|---|
| `HELIUS_API_KEY` | [helius.dev](https://helius.dev) | Deployer history check |
| `BIRDEYE_API_KEY` | [birdeye.so](https://birdeye.so) | Accurate top-holder data |

### Bot Tuning

| Variable | Default | Description |
|---|---|---|
| `MIN_SCORE` | `58` | Min score to post (0–100) |
| `MIN_LIQUIDITY_USD` | `8000` | Min liquidity |
| `NEW_TOKEN_MIN_MC` | `15000` | Min MC for new tokens |
| `NEW_TOKEN_MAX_MC` | `800000` | Max MC for new tokens (early entry window) |
| `NEW_TOKEN_MAX_AGE_H` | `3` | Hours to consider a token "new" |
| `OLD_TOKEN_MIN_5M_PCT` | `12` | 5m % spike required for old tokens |
| `POST_COOLDOWN_MS` | `3600000` | 1 hour between posts |
| `PUMPER_MULTIPLES` | `2,3,5,10` | Alert at these gain multiples |
| `MAX_POOL_SIZE` | `15` | Max candidates in memory (keep RAM low) |

## 🎯 Strategy

```
Every 5 seconds: check if 1 hour has passed since last post
  └─ Yes → pick BEST candidate from pool → deep analyze → post if score ≥ 58

Candidates come from:
  1. Telegram source chats (live listener)
  2. DexScreener latest profiles + boosts (every 3 min)

A candidate is accepted only if:
  New token  (< 3h old)  → MC between $15K–$800K
  Old token  (> 3h old)  → 5m price spike ≥ +12%

Deep analysis checks:
  ✅ Mint authority renounced  (mandatory — instant reject if not)
  ✅ Freeze authority off       (mandatory — instant reject if not)
  ✅ Top-10 holders < 45%
  ✅ No dev nuke (price drop > -60%)
  ✅ LP burnt/locked
  ✅ Buy/sell ratio
  ✅ Volume & trade count
  ✅ Deployer history
  ✅ Socials present
```
