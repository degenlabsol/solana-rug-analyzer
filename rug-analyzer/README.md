# Rug Analyzer PRO v3.2

**24/7 Solana Safe Low-Cap Hunter — Telegram Userbot**

Scans source Telegram chats, filters rugs with hard security checks, scores tokens out of 100, and posts the **best one per hour** to your channel. Runs on any device: Linux server, Windows PC, or Android phone (Termux).

---

## Features

- Multi-API analysis: DexScreener, GeckoTerminal, RugCheck, Birdeye, Helius
- Hard security gates: Mint authority + Freeze authority must both be renounced
- 100-point scoring: Liquidity, Security, Holders, Volume, Trades, Deployer history
- Best call per hour: collects all candidates, picks the top scorer every hour
- Early gem priority: low-cap new tokens ($15K–$800K MC, under 3 hours old)
- Old token hype detection: accepts older tokens only on a 5m spike of +12% or more
- Pumper alerts: automatic updates at 2X, 3X, 5X, 10X
- Leaderboard: top gainers posted every 8 hours
- Low RAM usage: sequential API calls, minimal in-memory state, pool capped at 15 entries

## Configuration

After running the install script, edit your `.env` file:

```bash
nano .env          # Linux / Termux / macOS
notepad .env       # Windows
```

### Required Variables

| Variable | Example | Description |
|---|---|---|
| `TELEGRAM_API_ID` | `123456` | From [my.telegram.org/apps](https://my.telegram.org/apps) |
| `TELEGRAM_API_HASH` | `abc123...` | From [my.telegram.org/apps](https://my.telegram.org/apps) |
| `TELEGRAM_SESSION` | `1BQA...` | Generated by `node generate-session.js` |
| `POST_CHAT_ID` | `@mychannel` | The channel where the bot posts calls |
| `SOURCE_CHAT_IDS` | `chat1,chat2` | Source chats to monitor (comma-separated, no @) |

### Optional API Keys (improve analysis quality)

| Variable | Service | What it adds |
|---|---|---|
| `HELIUS_API_KEY` | [helius.dev](https://helius.dev) (free tier available) | Deployer history check |
| `BIRDEYE_API_KEY` | [birdeye.so](https://birdeye.so) (free tier available) | Accurate top-holder data |

### Tuning Variables (all optional — defaults shown)

| Variable | Default | Description |
|---|---|---|
| `MIN_SCORE` | `58` | Minimum score out of 100 to post a call |
| `MIN_LIQUIDITY_USD` | `8000` | Minimum liquidity in USD |
| `NEW_TOKEN_MIN_MC` | `15000` | Minimum market cap for new tokens |
| `NEW_TOKEN_MAX_MC` | `800000` | Maximum market cap for new tokens |
| `NEW_TOKEN_MAX_AGE_H` | `3` | Max age in hours to count as a "new" token |
| `OLD_TOKEN_MIN_5M_PCT` | `12` | Required 5-minute price spike for older tokens |
| `POST_COOLDOWN_MS` | `3600000` | Time between posts in ms (default: 1 hour) |
| `PUMPER_MULTIPLES` | `2,3,5,10` | Notify at these gain multiples |
| `MAX_POOL_SIZE` | `15` | Max candidates held in memory |

## How It Works

```
Every 5 seconds: check if 1 hour has passed since last post
  └── Yes → pick best candidate from pool → deep analyze → post if score >= 58

Candidates come from:
  1. Live listener on source Telegram chats
  2. DexScreener latest profiles + boosts (polled every 3 minutes)

A candidate is accepted in the pool only if:
  New token  (< 3h old)  → MC between $15K and $800K
  Old token  (> 3h old)  → 5m price spike >= +12%

Deep analysis (sequential API calls):
  ✅ Mint authority renounced    — mandatory, instant reject if not
  ✅ Freeze authority off        — mandatory, instant reject if not
  ✅ Top-10 holders < 45%
  ✅ No dev nuke (>-60% price drop)
  ✅ LP burnt or locked
  ✅ Buy/sell ratio
  ✅ Volume and trade count
  ✅ Deployer history
  ✅ Socials present

Best candidate is selected by: Liquidity × (MC bonus for early gems)
```

## Troubleshooting

**AUTH_KEY_DUPLICATED error**
The same session is being used on two devices simultaneously. Stop the bot on the other device first, wait 15 seconds, then restart.

**AUTH_KEY_UNREGISTERED error**
Your session has expired or been revoked. Run `node generate-session.js` again to create a new one.

**Bot starts but never posts**
- Check that `SOURCE_CHAT_IDS` contains active chats with token addresses
- Confirm your API keys are set correctly
- Lower `MIN_SCORE` temporarily (e.g. to `45`) to test posting works
- Check logs: `pm2 logs rug-analyzer`

**No candidates in pool**
The fallback poller runs every 3 minutes and scans DexScreener for new tokens. Wait a few minutes after startup.

**Rate limit errors (429)**
Normal — the bot retries automatically with a delay. No action needed.
